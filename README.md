# Chemistry Chapter 7 Interactive Quiz

A self-contained static quiz for GitHub Pages. No build tools or external dependencies are required.

## Features
- Multiple-choice questions with instant correctness feedback and explanations
- Saves answers in browser `localStorage` on the current device/browser
- Per-section progress and final report
- Export answer report as JSON or CSV
- Responsive layout for desktop and mobile

## Publish with GitHub Pages
1. Create a new repository on GitHub (for example, `chemistry-chapter7-quiz`).
2. Upload `index.html` to the repository root and commit it to the `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish the site. The public URL will be shown in the Pages settings.
